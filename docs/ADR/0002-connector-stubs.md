# ADR-0002: Karma 与电商连接器先以 stub 交付

- 问题：真实 Karma/电商 API 合同尚未提供，但平台需要可验证的回执闭环。
- 候选：阻塞等待真实 API / 先用带真实回执结构的 stub。
- 决策：stub（`app/connectors.py`），保留 `Connector` 协议与 `execute`/`verify`。
- 理由：网关、核验、审计、幂等逻辑可先行开发并测试，不依赖外部系统。
- 风险：stub 回执不代表真实交易；真实接入后需重新验证幂等与 UNKNOWN 语义。
- 迁移成本：实现同一协议的真实连接器类并替换注册表即可，执行网关无改动。
- 重新评估条件：Karma/电商开放平台文档到位时。
