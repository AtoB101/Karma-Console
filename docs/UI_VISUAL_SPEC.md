# KARMA SUPER CONSOLE — 前端视觉落地规格（视觉标杆）

> 用途：以用户提供的参考仪表盘为**最终视觉标杆**，拆解为后期套皮对照表。
> 边界：本轮后端推进期间 `app/static/holo.html` 保持冻结，**不重写**；待用户提供完整前端代码后，按本规格逐项对齐落地。本文只记录视觉与信息架构，不代替可运行前端。
> 标杆来源：用户提供的 KARMA SUPER CONSOLE 参考截图（本地剪贴板附件）。

## 1. 整体版式（16:9 桌面大屏，深蓝青蓝全息风）

|---|---|---|
| 左导航栏 | 最左，固定窄栏，深色半透明 | 一级菜单，当前项青色高亮 |

## 8. 最底部语音/文字输入条

- 左侧圆形头像 +「你好，{用户名} / 企业管理员」；齿轮设置；中央大麦克风圆形按钮；输入框提示「你可以对我说：」附示例 chips：创建一个客户管理面板 / 分析行业新闻并生成报告 / 查看今日任务进度 / 帮我查询一下库存情况；右侧发送箭头条；最右声波可视化图标。
- 支持文字输入与语音，输入后由主脑解析并打开对应面板（对话流驱动）。

## 9. 视觉语言（后期套皮必须对齐）

- **底色**：深蓝黑 `#050b1e` → `#0a1530` 径向渐变，背景虚化城市夜景 + 反光地面。
- **主色**：青蓝 `#2f9bff` / 霓虹青 `#38e0ff`；状态绿 `#33d69f`；警告/待确认琥珀 `#f5a623`；进行中蓝、已完成绿、待开始灰。
- **点缀**：品红仅在光带/强调处少量出现，不铺满。
- **材质**：玻璃拟态（半透明 rgba 蓝底 + 1px 青蓝描边 + 大圆角 + 柔和外发光），卡片轻微悬浮阴影。
- **光**：球体体积光、底座环形光、地面反射；整体 HDR、通透、低噪点。
- **动效目标**（后期实现）：卡片悬浮微浮动、球体缓慢旋转、光带缓流、面板滑入滑出丝滑；点选面板滑到主屏时主脑/球体淡化、面板清晰，主脑不移位。
- **字体**：无衬线中文，数字用等宽/科技感字体；层级：大标题 > 主数字 > 卡片标题 > 副文案 > 辅助说明。
