# 智能获客 × 智能客服 · 底层能力蓝图与全链路路线

> 目标：把"获客 → 培育 → 接待 → 成交 → 售后 → 复购 → 复盘"做成超级控制台的底层引擎，
> 能力对标并超越市场主流 SCRM / 智能客服 SaaS，同时守住本地隐私、E2EE、安全边界，不伪造任何外部渠道联调。

## 1. 市场主流系统能力对标（调研归纳）

| 能力域 | 市场主流做法（探迹/尘锋/美洽/智齿/有赞/瓴羊Quick Service/Intercom/Tidio/多客Duoke） | 本系统现状 | 增强方向 |
|---|---|---|---|
| 全渠道获客 | 渠道活码/短链/门店码/裂变/广告/外呼，统一沉淀客户 | 仅本地建档 | 先做"渠道来源登记位+来源归因"，外部渠道留真实凭证位，不伪造 |
| 线索评分分级 | AI行为评分，H/A/B/C 或 热/温/冷，高分当天分配 | 无评分 | 本地规则评分（意向信号+互动+资料完整度），分层分流 |
| 智能分配 | 按规则/负载/轮询自动分配，超时回收公海 | 无 | CEO 分派器按负载/技能自动派单，超时未触达自动提醒/回收 |
| 跟进SOP节奏 | 3-5-7 法则，定时提醒任务，资料/案例/演示组合触达 | 无 | SOP 节奏引擎，自动生成待办提醒，记录每次触达 |
| AI接待应答 | 7×24 知识库命中、多轮对话、主动引导留资 | 主脑可应答，无专用话术库 | 知识库FAQ自动命中+话术推荐，命中置信度不足转人工 |
| 转人工识别 | 意图识别（投诉/退款/复杂/情绪激动）自动转 | 无 | 规则+关键词+情绪信号触发转人工队列，带上下文 |
| 工单闭环 | 会话一键开工单，自动分类/优先级/超时升级/回访闭环 | 无 | 工单生命周期：受理→处理→回访→关闭，超时升级 |
| 会话质检 | 全量会话自动打标、合规/承诺/风险词扫描 | 无 | 本地质检：风险词、过度承诺、合规提示，仅日志不外发 |
| 客户画像 | OneID跨渠道聚合，画像标签、偏好、历史 | 有 profile | 画像聚合：偏好/采购/沟通记录/标签，服务主脑个性化 |
| 成交转化 | 记录win、漏斗各阶段转化率、周期、客单价 | 有 record_win | 转化漏斗看板：new→lead→won/lost，阶段转化率 |
| 复购留存 | 分层运营、召回、复购提醒、会员 | 无 | 成交后自动复购提醒/回访任务，沉睡客户召回清单 |
| 数据看板 | 获客量、响应时长、解决率、满意度、ROI | 部分只读 | 获客客服专用看板（响应/解决率/满意度/转化/漏斗） |
| 全量质检复盘 | 周期LLM复盘会话，沉淀新FAQ/新话术 | 无 | 会话复盘→沉淀知识/话术，形成自学习闭环 |

## 2. 本系统差异化（要比市场强的点）

1. **隐私原生**：客户敏感信息（真实姓名、资金、收款凭据、私聊原文）E2EE，服务端只存密文，密钥不出端；市场SaaS多为云端明文托管。
2. **主脑CEO统一神经分派**：获客线索、客服会话、工单全部进CEO分派器，按P0-P3优先级与技能自动派单，越界（收款/退款/改价/改政策）自动升级老板拍板，不越权。
3. **本地零知识**：所有评分、SOP、画像、质检在本地算，不上传平台；可做零知识式真实性校验而不泄露原文。
4. **自营闭环优先**：先把"自己上传的商品/客户/订单/库存"跑通，外部物流/渠道只留凭证位，绝不伪造联调成功。
5. **可审计可回溯**：每次触达、应答、转人工、工单、成交都落审计哈希链，可追溯。

## 3. 全链路（Lead → Serve → Close → Retain → Learn）

```
[获客来源登记] → [线索评分/分级 H-A-B-C] → [CEO自动分配/派单]
   → [SOP节奏触达: 3-5-7] → [AI接待: FAQ命中/话术推荐]
   → [命中不足→转人工队列(带上下文)] → [成交 record_win → 订单/发货]
   → [售后工单闭环 → 回访] → [复购/沉睡召回] → [会话复盘 → 沉淀FAQ/话术] → 回到评分
```

## 4. 分阶段路线（稳步推进，每阶段可独立验证）

### P0 底座（本轮起）
- 客户表扩展：`score`(评分)、`grade`(分级)、`source`(来源渠道)、`next_follow_at`(下次跟进)、`owner`(负责经理人)、`last_touch_at`、`satisfaction`。
- 线索规则评分引擎：资料完整度 + 互动/意向信号（咨询/问价/问库存/预约）加权出分，自动分级。
- 跟进待办：SOP节奏自动生成提醒（3天/5天/7天节点），可在任务中心看到。
- 只读端点：线索分级列表、待跟进清单、评分分布。

### P1 智能接待与工单
- 知识库FAQ：本地FAQ条目（问题→标准答→关联商品/话术），AI应答先命中FAQ。
- 话术推荐：按意图推荐Script，记录 sends/wins 转化。
- 转人工规则：投诉/退款/强烈不满/答不准 → 进人工队列，携带会话上下文。
- 工单：受理→处理中→待回访→已关闭，超时升级提醒。

### P2 看板与自学习
- 获客客服看板：响应时长、解决率、满意度、漏斗转化、分级分布。
- 会话复盘：周期汇总高频问题/未命中，建议新增FAQ，沉淀话术。
- 复购召回：成交客户定时回访、沉睡客户清单。

## 5. 安全边界（不可突破）
- 收款、退款、争议、批量调价、改政策阈值 → 一律老板确认码（沿用 FORCE_ESCALATE）。
- 外部渠道（微信/抖音/电话/物流商）只登记凭证位与联调状态，不假装已连通。
- 客户私聊原文、真实姓名、资金凭据加密存储，前端默认脱敏展示。
- 所有自动化只做"建议/待办/草稿"，对外发送与不可逆动作需人工或老板放行。

## 6. P0 线索评分规则（本地规则引擎，先不接大模型）

分数 0–100，按信号加权累计，落到四级：H(≥80 热)/A(60–79 温)/B(40–59 淡)/C(<40 冷)。

| 信号 | 权重 | 说明 |
|---|---|---|
| 主动问价/索取报价单 | +30 | 强购买意向 |
| 咨询具体商品规格/库存/能否发货 | +22 | 明确需求 |
| 预约演示/到店/留联系方式 | +25 | 高意向 |
| 问售后/质保/退换政策 | +12 | 稳妥意向 |
| 多次回访/重复咨询（≥2次） | +10 | 关注度高 |
| 资料完整（姓名+来源+备注齐全） | +8 | 可联系性 |
| 询过价但未成交（30天内） | +6 | 可再触达 |
| 明确拒绝/问完即走/失联 | -25 | 降为C并观察 |

派生动作：
- H/A：当天自动派单给客服经理人，生成"15–30分钟首触"待办。
- B：排入4小时内触达队列，SOP跟进。
- C：进入培育/公海，定期复盘，不占用热线资源。

## 7. SOP 跟进节奏（3-5-7 法则本地任务引擎）

| 节点 | 动作 | 落账 |
|---|---|---|
| D0 当天 | 首触：欢迎语 + 需求确认 | 自动建待办，记录触达 |
| D3 | 第1次跟进：发资料/案例，确认痛点 | 未跟进自动提醒 |
| D5 | 第2次跟进：方案/报价建议，促决策 | 超时升级提醒 |
| D7 | 第3次跟进：明确下一步（转商机/成交/关闭） | 无回应转C培育 |
| 成交后D7 | 回访确认收货/满意度，引导复购 | 建回访待办 |

每次触达写一条 Message/跟进记录，更新 last_touch_at 与 next_follow_at。

## 8. 工单状态机（售后/投诉闭环）

```
new(受理) → processing(处理中) → waiting_reply(待客户回复/待回访)
        → closed(已关闭)；任何状态可 escalated(超时升级老板)
```
- 受理：会话一键开工单，自动带入客户/订单/渠道/会话摘要。
- 自动分类与优先级：投诉/退款/高价值客户优先（规则+关键词，P2阶段接LLM）。
- 超时：未在SLA内响应自动升级提醒；关闭前模型/人工回访确认解决。

## 9. 全链路 KPI 看板（只读聚合）

| 板块 | 指标 |
|---|---|
| 获客 | 新增线索数、来源渠道分布、H/A/B/C分级分布 |
| 响应 | 首响时长、平均响应时长、超时未触达数 |
| 接待 | FAQ命中率、转人工率、AI自助解决率 |
| 转化 | new→lead、lead→won 阶段转化率、销售周期、客单价 |
| 售后 | 工单量、平均处理时长、超时升级数、回访闭环率 |
| 满意 | 满意度评分、好评/差评、NPS（P2） |
| 留存 | 复购率、沉睡客户召回数 |

## 10. 数据结构扩展清单（迁移用，向后兼容、可空默认）

- `customers` 增列：score INT(默认0)、grade TEXT、source TEXT、owner_id TEXT、
  last_touch_at DATETIME、next_follow_at DATETIME、satisfaction REAL。
- 新增 `tickets` 表：id/workspace_id/customer_id/order_id/channel/type/priority/
  status/assignee_id/title/description/created_at/updated_at/closed_at。
- 新增 `faq` 表：id/workspace_id/question/answer/related_products/tags/hits/created_at。
- 话术 Script 已有 sends/wins，P1 补"按意图推荐"。

## 11. 阶段验收口径
- P0：客户列表能看到评分/分级/来源/下次跟进；待跟进清单可点直达；评分由本地规则算出，无外部调用。
- P1：FAQ可命中并推荐话术；答不准/投诉/退款自动进人工队列；工单可建可流转可关闭。
- P2：看板聚合真实本地数据；会话复盘沉淀FAQ；复购召回清单生成。
- 全程：不伪造外部渠道联调，资金/退款/改价/改政策仍走老板拍板。
