### 🟡 刻意只读 / 暂不在首屏直给（附客观原因）
| 面板 | 状态 | 原因 |
|---|---|---|
| 支付结算 ledger | 只读汇总 | 真实 Karma 资金/扣款/退款争议未联调，不伪造流水 |
| 商家资源 merchant | 只读 | 后端无店铺/工作区资料 PATCH 端点；渠道登记在连接面板 |
| 数据分析 analytics | 只读图表 | 聚合看板本就只读，写动作不在此层 |
| 应用市场模块（/marketplace） | 不在首屏 | 模块安装需 ModuleInstall payload（404/403/409），留完整工作台；首屏「技能市场」(/skills) 已可装/卸 |
| 账户 account / 经营总览 overview / 系统状态 system | 总览：KPI/待审批/待办/经营目标（只读+新建+标记完成/重开+进度备注）；系统面板含实时告警 `/alerts`、定时任务 `/jobs`（可启停、可删除）、就绪自检、运行计数 | 展示型面板；配置变更走设置面板；告警派发需 owner |
| 签名渠道（淘宝/抖店/顺丰）、Basic 鉴权、动作映射 | 不在首屏 | 参数多且敏感，留完整工作台；首屏仅登记通用 HTTP |
| 设备 request/authorize | 不在首屏 | 依赖设备端 Passkey/WebCrypto 注册，非纯表单可完成 |
